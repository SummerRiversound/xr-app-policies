# Cutbench: XR 영상 편집기 / XR Video Editor

Android XR에서 짧은 영상을 자르고, 나누고, 순서를 바꾸고, 페이드·타이틀·속도·배경 음악을 넣어 MP4로 내보내는 영상 편집기입니다.

A video editor for Android XR: trim, split and reorder short clips, add fades, titles, speed and background music, and export one MP4.

- Google Play: Cutbench: XR Video Editor (Android XR)
- 개인정보처리방침 / Privacy policy: [privacy/](privacy/)
- 문의 / Contact: summer.riversound@gmail.com

알아 두세요 / Good to know

- Android XR 기기(XR 헤드셋 또는 유선 XR 안경)용입니다. / For Android XR devices (XR headsets or wired XR glasses).
- 영상은 시스템 파일 선택 창에서 고른 파일만 읽고, 내보낸 파일은 Movies/Cutbench에 저장됩니다. / Cutbench reads only the files you pick in the system file picker and saves exports to Movies/Cutbench.
- 계정·광고·인앱 결제가 없고, 인터넷을 쓰지 않으며, 영상과 프로젝트는 기기 안에만 있습니다. / No account, ads or in-app purchases; no internet use; videos and the project stay on the device.
