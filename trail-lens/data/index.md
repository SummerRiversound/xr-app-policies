# Trail Lens 장소 데이터베이스 / Place database

Trail Lens가 주변 장소를 보여 줄 때 내려받는 칸 파일 전체입니다. / The full set of cell files Trail Lens downloads to show nearby places.

- [trail-lens-cells-v1.zip](trail-lens-cells-v1.zip)
- © OpenStreetMap contributors. 이 데이터베이스는 [Open Database License 1.0](https://opendatacommons.org/licenses/odbl/1-0/)으로 제공됩니다. / This database is made available under the Open Database License 1.0.
- 형식 / Format: 0.1° 칸마다 TSV 파일 하나(`v1/<row>_<col>.tsv`), 첫 줄은 헤더, 각 줄은 OSM id, 종류, 위도, 경도, 멀리서 보이는지(1/0), 이름, 영어 이름. / One TSV per 0.1° cell; first line is a header; each row is OSM id, kind, latitude, longitude, visible-from-far flag (1/0), name, English name.
